# v11 review: "Gambit" (concept C05, Dioramas "Gambit" world ported)

**Concept:** "Every draft is a game of chess." The home page is a marble chess salon in WebGL: glossy board with planar reflections, low-key studio light, carved pieces (Dioramas CC BY models). Scroll replays the Immortal Game (Anderssen–Kieseritzky, 1851): pieces slide, knights arc, captures topple. A score sheet tracks each move with a one-line annotation, the same thing AOBS's draft and stats graphics do for an MLBB series. After mate, free play: drag any piece.
- **Draft section:** the real PCC grand-final pick/ban board, spec rows (bans, picks, series, then HUD) and in/out cards (draft feed → pick/ban board).
- **Match day:** holding screen T−15, pick and ban T−5, game 00:00 with the backup stream underneath.
- **Look:** black, bone and brass; Bodoni Moda + Inter (self-hosted).
