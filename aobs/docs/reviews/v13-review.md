# v13 review: "Power Up" (concept C06, Dioramas "Hangar Nine" world ported)

**Concept:** "Hold to go live." The AOBS production rig drawn as a machine in a dark hangar. Holding the gauge (or Space) runs a boot sequence: Gallery power OK → Monitor wall 12/12 → Backup path hot → Observer feeds 3/3 → Graphics package loaded → Game data synced → Encoders online → Programme ready to air. Scrolling orbits hotspots, each a broadcast system with a holographic scan: Backup core (Backup Streamer), Observers, Graphics (per-event identity), Sponsors (Mini Mayhem's 3 formats). Then the numbers (18 / 4 / 3 / 3), the run-up (brief → identity → rig → air), "You bring" (the organizer checklist) and the quote. The test-pilot portrait was removed (no-people rule).
**Look:** gunmetal, hazard amber, HUD cyan; Chakra Petch + Rajdhani + Share Tech Mono.
