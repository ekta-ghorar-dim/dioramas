# v12 review: "Movement" (concept C08, Dioramas "Aurel Horologie" world ported)

**Concept:** "Fourteen layers. One programme. No dropped beats." A rose-gold skeleton watch tilts with the cursor on ivory; scrolling explodes a fully procedural movement (gears at true ratios, balance at 4 Hz). Every part is **labelled as a layer of an AOBS broadcast**: Viewer output (crystal), Scorebug (hands), Identity (dial), Graphics package (bridges), Sponsor formats (winding works), **Backup Streamer (barrel, the reserve)**, Switcher (going train), Observers (tourbillon), Game data (escapement), Replay (balance), Casters, AOBS Cloud (mainplate). Hold the crown to wind the "backup reserve".
- **Sections:** Fig. I–V explain the stack. "Details" covers holding screens T−15, the Bo5 PCC draft board and 3 sponsor formats. "Production models" covers venue, remote and hybrid. "On record": 18 / 4 / 3 / 3. Then the quote.
- **Look:** ivory, navy, rose gold; Cormorant Garamond + Montserrat. Light mode, precise, editorial.
