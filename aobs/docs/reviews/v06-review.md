## Client feedback during v06 (verbatim intent)
"All designs look similar, with the same ON AIR texts, same text. Think properly. Make unique designs, not AI-slop ones."

## Honest assessment
The client is right. v01–v06 are **one design wearing six outfits**:
- The same hero pattern: a huge headline, two CTAs, an ON AIR tally pill and a running timecode.
- The same uppercase letter-spaced mono "eyebrow" with a dot or dash above every heading.
- The same section order and the same copy in every version.
- Generic "premium AI site" tropes: gradient text, glow buttons, glass panels, numbered 01/02 lists, decode-scramble titles, grain.

## What changes from v07
Each version starts from a **concept** with its own IA, copy, interaction model and graphic system. Banned across all new directions unless the concept genuinely needs it: ON AIR pills, running timecodes, mono eyebrow labels, gradient text, glows, glass cards, scramble text, and "Every frame / on air" style slogans.
