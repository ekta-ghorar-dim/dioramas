# v19 review: "Monolith" (concept C16, Dioramas "Monolith" world ported)

**Concept:** "From load-in to the last game." A board-marked concrete cliff house on a plinth; the sun is a handle. Dragging it (or the day bar, or "play the day") moves through one AOBS show day. The HUD phases are rewritten as load-in → line check → rehearsal → holding screen → group matches → match day → playoffs → **the final** (sunset, golden grade) → wrap → post-show, with real-time sweeping shadows.
- **Selected work:** five events with hover-reveal images (PCC, the PCC campaign, Mini Mayhem, Women's War, Halloween Fest), all real AOBS imagery.
- **Case study "The grand final, hour by hour":** holding screen T−15 → draft (Bo5) → in-game HUD. The section cut is relabelled as broadcast layers (L5 viewer output, L4 graphics & data, L3 gallery, L0 Backup Streamer); plan tags show holding screen / draft board / HUD / gallery.
- **Principles:** running order before graphics, one identity, data is a material, never go dark.
- **Crew:** a real PCC frame, 18 / 4 / 3 / 3, tools and titles. Then the quote.
**Look:** concrete, paper, golden-hour orange; Inter Tight + IBM Plex Serif italic + Plex Mono.
