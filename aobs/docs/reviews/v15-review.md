# v15 review: "Abyss" (concept C09, Dioramas "Abyssal" world ported)

**Concept:** "What your viewers see is the surface. We run the rest." Scroll is a dive from sunlit water to the trench floor. A depth gauge relabelled as broadcast layers (Programme → Data → Gallery → Cloud → Backup → The floor) tracks the descent. Each zone card is one layer of an AOBS broadcast with real facts and links (PCC HUD, the Bo5 draft board, observers/switcher, AOBS Cloud, Backup Streamer). Floodlights steer with the pointer; click for a sonar ping. The submersible's hotspots are relabelled (gallery, observers, Backup Streamer, graphics & data). The named-crew section became a redundancy section (no people). The $750k seat pricing became a brief checklist plus a real event table.
**Look:** abyssal black-teal, cyan, safety orange; Space Grotesk + IBM Plex Mono.

**Bug found and fixed:** an old site-wide `.stage { display: none }` rule from v07 hid Abyssal's `.stage` sections. It's removed in v15. Lesson: imported world CSS and the site's global CSS share one namespace.
