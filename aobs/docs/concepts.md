# AOBS design concepts (32), with the Dioramas repo as the technique library

Source studied: `ekta-ghorar-dim/dioramas` (cloned at `/home/user/ekta-ghorar-dim/dioramas`). It holds 20 cinematic 3D landing pages on a shared three.js engine: HDR post (N8AO, bloom, AgX), volumetric spotlights, planar reflections, GPU-baked textures, Lenis + GSAP choreography, one signature interaction per page. Code is MIT; its models and images are CC BY 4.0 (credit "Dioramas (github.com/blendi-remade/dioramas)" wherever one is used).

**Rules for every concept** (from the client feedback and the Dioramas quality bar):
- Its own idea, information architecture, copy, palette, type pairing and motion language.
- One signature interaction that sells something AOBS really does.
- None of the v01–v06 tropes: ON AIR pills, running timecodes, mono eyebrow labels, gradient text, glass cards, scramble titles, "every frame" slogans.
- Only real AOBS facts. The real broadcast frames, key visuals and teasers are the proof layer.
